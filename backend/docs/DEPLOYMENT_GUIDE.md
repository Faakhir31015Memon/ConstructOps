# DEPLOYMENT & OPERATIONS GUIDE — CONSTRUCTOPS
**Target Environments:** Staging & Production  
**Architecture:** Decoupled Backend (Node/Express API) + Frontend (Vite/React Static SPA) + MongoDB Atlas  

---

## 1. Environment Configuration

### 1.1 Backend Environment Variables (`backend/.env`)
```env
PORT=5000
NODE_ENV=production
MONGO_URI=mongodb+srv://<username>:<password>@cluster0.mongodb.net/constructops?retryWrites=true&w=majority
JWT_SECRET=super_secure_random_64_character_hex_secret_key_here
CORS_ORIGIN=https://app.constructops.com
```

### 1.2 Frontend Environment Variables (`frontend/.env`)
```env
VITE_API_URL=https://api.constructops.com/api/v1
```

---

## 2. Repository Layout

The repository contains two directories only:

- `backend/` — Express API, Mongoose models, serverless entry (`backend/api/[...all].js`), planning docs (`backend/.planning/`), and this documentation set.
- `frontend/` — Vite/React SPA.

## 3. Local Development Startup

1. **Install Backend:**
   ```bash
   cd backend && npm install
   ```
2. **Start Backend:**
   ```bash
   npm run dev
   ```
3. **Install & Start Frontend (second terminal):**
   ```bash
   cd frontend && npm install && npm run dev
   ```

---

## 4. Production Build & Deployment Options

### Option A: Standard Cloud VM / Container (Docker / AWS ECS / DigitalOcean)
- **Backend:** Node.js long-running process managed by `pm2` or Docker container:
  ```bash
  cd backend
  npm start
  ```
- **Frontend:** Nginx serving the static `dist/` bundle generated by `npm run build` in `frontend/`.

### Option B: Cloud Platform / Serverless (Vercel)
- `backend/vercel.json` is the deployment configuration; the Vercel project **Root Directory must be `backend`**.
- `backend/api/[...all].js` maps every `/api/*` request to the Express app; all other paths rewrite to the SPA `index.html`.
- `outputDirectory` is `../frontend/dist`, so the build command compiles the frontend from the backend root.
- If an existing Vercel project still points at the repository root, repoint it at `backend` before deploying.
- **Note:** Background workers, socket connections, and long-running report generations should be hosted on a persistent Node.js runtime.
